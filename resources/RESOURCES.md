# Learning Resources

A curated list of books, documentation, and references that support the machine learning curriculum.

## Books

- **Hands-On Machine Learning with Scikit-Learn, Keras, and TensorFlow** by Aurelien Geron
  - Practical guide with code examples covering classical ML and deep learning.
- **Pattern Recognition and Machine Learning** by Christopher Bishop
  - A rigorous theoretical treatment of machine learning algorithms.
- **Deep Learning** by Ian Goodfellow, Yoshua Bengio, and Aaron Courville
  - Comprehensive reference for modern deep learning, available free online at https://www.deeplearningbook.org/

## Official Documentation

- **Python**: https://docs.python.org/3/
- **NumPy**: https://numpy.org/doc/
- **Pandas**: https://pandas.pydata.org/docs/
- **Matplotlib**: https://matplotlib.org/stable/contents.html
- **Seaborn**: https://seaborn.pydata.org/
- **Scikit-learn**: https://scikit-learn.org/stable/
- **SciPy**: https://docs.scipy.org/
- **PyTorch**: https://pytorch.org/docs/stable/

## Mathematics

- **Khan Academy** (https://www.khanacademy.org/)
  - Free courses in linear algebra, calculus, statistics, and probability.
- **3Blue1Brown** (https://www.3blue1brown.com/)
  - Visual explanations of linear algebra, calculus, and neural networks.
- **MIT OpenCourseWare - Linear Algebra** (https://ocw.mit.edu/courses/18-06-linear-algebra-spring-2010/)
  - Gilbert Strang's classic linear algebra lectures.
- **StatQuest** (https://statquest.org/)
  - Short, accessible videos on statistics and machine learning.

## Datasets

The `datasets/` folder contains the synthetic and sample data used for the first four projects:

- `ecommerce_customers.csv` - Python for ML practice
- `employees.csv` - Project 1 final challenge
- `iris.csv` - NumPy / k-NN practice
- `customer_behavior.csv` - Statistics and EDA practice
- `house_prices.csv` - Linear regression practice

## Recommended Reading Order

1. **Beginner**: Start with the official documentation for Python, NumPy, and Pandas.
2. **Foundations**: Watch 3Blue1Brown's linear algebra and calculus playlists.
3. **Classical ML**: Work through the Scikit-learn user guide alongside the project notebooks.
4. **Deep Learning**: Read the fast.ai course material and Goodfellow's *Deep Learning*.
