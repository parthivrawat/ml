# Project 3: Statistics & Exploratory Data Analysis

## Overview

**Level**: Foundation (Level 0)  
**Prerequisites**: Projects 1-2  
**Estimated Time**: 12-15 hours  
**Notebook**: `03_statistics_and_eda.ipynb`

## Learning Objectives

- Master descriptive statistics (mean, median, variance, etc.)
- Understand probability distributions
- Perform comprehensive exploratory data analysis
- Create meaningful visualizations
- Understand correlation vs. causation
- Identify data quality issues
- Make data-driven decisions

## Project Description

**Analyze Customer Behavior Dataset**

Perform a complete statistical analysis and EDA on a customer dataset, learning both theory and practice.

## Topics Covered

### Statistics Fundamentals
- Measures of central tendency (mean, median, mode)
- Measures of dispersion (variance, std, range, IQR)
- Distributions (normal, uniform, binomial, etc.)
- Probability basics
- Conditional probability and Bayes' theorem
- Sampling and confidence intervals
- Hypothesis testing (t-test, chi-square)

### EDA Techniques
- Univariate analysis
- Bivariate analysis
- Multivariate analysis
- Outlier detection
- Missing data analysis
- Distribution analysis
- Correlation analysis
- Feature relationships

### Visualizations
- Histograms and density plots
- Box plots and violin plots
- Scatter plots and pair plots
- Heatmaps
- Bar charts and count plots
- Time series plots

## Key Exercises

1. Calculate all statistics manually with NumPy
2. Implement hypothesis tests from scratch
3. Create a complete EDA report
4. Identify and handle outliers
5. Detect suspicious patterns
6. Make business recommendations

## Final Challenge

Perform independent EDA on a new dataset and present findings as a data analyst would to stakeholders.
