# Contributing

Thank you for your interest in improving this project.

## How to contribute

1. **Open an issue** first for bugs, typos, or feature suggestions.
2. **Fork the repository** and create a branch from `development`.
3. **Make focused changes** with clear, descriptive commit messages.
4. **Open a pull request** against `development` and fill out the template.

## Style guidelines

- Follow the existing naming conventions for notebooks and project documents.
- Write clean, well-commented code. Avoid `TODO` markers and placeholders.
- Ensure notebooks run end-to-end before opening a pull request.
- Keep each notebook focused on the project it represents.
- Add datasets only if they are small and publicly licensed; otherwise link to the source.

## Ground rules

- Be respectful and constructive.
- Keep changes small and reviewable.
- Make sure all existing notebooks still run if your change affects dependencies.
