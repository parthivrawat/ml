# Glossary

> Reference guide for machine learning terms used in this curriculum

---

## A

- **Algorithm**: A step-by-step procedure that maps input features to a target or pattern.
- **Anomaly detection**: Identifying observations that differ significantly from the majority of the data.

## B

- **Baseline**: A simple, inexpensive model used as a reference for comparison.
- **Bias (error)**: Systematic error caused by assumptions that are too simple.
- **Bias (parameter)**: An intercept or constant term added to a model.

## C

- **Classification**: Predicting a discrete category or class label.
- **Clustering**: Grouping unlabeled data so that similar points are in the same group.
- **Convergence**: The point where an iterative algorithm reaches a stable solution.
- **Cost function**: A mathematical function that measures how wrong a model's predictions are.
- **Cross-validation**: Resampling the data into multiple train/validation splits to estimate generalization performance.

## D

- **Data leakage**: Using information during training or preprocessing that would not be available at prediction time.
- **Decision boundary**: The surface that separates predicted classes or regions.
- **Dimensionality**: The number of features or columns in a dataset.
- **Dimensionality reduction**: Techniques such as PCA that reduce the number of features while preserving information.

## E

- **Eigenvalue / eigenvector**: A scalar/vector pair that describes how a linear transformation stretches or rotates a vector.
- **Ensemble method**: Combining multiple models to improve predictions, such as random forests or gradient boosting.
- **Epoch**: One complete pass through the entire training dataset during optimization.
- **Exploratory data analysis (EDA)**: Investigating data with summaries and visualizations before modeling.

## F

- **Feature**: An input variable used by a model.
- **Feature engineering**: Creating, transforming, or selecting features to improve model performance.
- **F1 score**: The harmonic mean of precision and recall, useful for imbalanced classification.

## G

- **Gradient**: A vector of partial derivatives that points in the direction of steepest ascent.
- **Gradient descent**: An optimization algorithm that iteratively moves parameters in the direction of the negative gradient.

## H

- **Hyperparameter**: A model setting that is not learned from the data and must be set before training.
- **Hypothesis**: A proposed model or mapping from inputs to outputs.

## I

- **Imputation**: Filling in missing values with substituted values.
- **Independence**: Two events are independent if the occurrence of one does not affect the probability of the other.
- **Inference**: Using a trained model to make predictions on new data.
- **Information gain**: A measure used to choose splits in decision trees based on reduced entropy.

## L

- **Label**: The target value or correct answer for a supervised learning example.
- **Learning rate**: A hyperparameter that controls the step size in gradient descent.
- **Linear regression**: A model that predicts a continuous target using a linear combination of features.
- **Loss function**: A function that measures the penalty for a single prediction.

## M

- **Metric**: A numeric measure used to evaluate model performance, such as accuracy or RMSE.
- **Model**: A learned representation that maps inputs to predictions.

## N

- **Normal distribution**: A symmetric, bell-shaped probability distribution.
- **Normalization**: Rescaling features so they have a similar range, often to improve optimization.

## O

- **One-hot encoding**: Converting a categorical variable into a set of binary columns.
- **Overfitting**: When a model learns the training data too closely and fails to generalize.
- **Outlier**: A data point that is unusual compared to the rest of the distribution.

## P

- **Parameter**: A value learned by the model during training, such as a weight.
- **Pipeline**: A sequence of preprocessing and modeling steps bundled together.
- **Precision**: The fraction of predicted positives that are actually positive.
- **Probability**: A measure of how likely an event is to occur, ranging from 0 to 1.

## R

- **Recall**: The fraction of actual positives that the model correctly identifies.
- **Regression**: Predicting a continuous numeric target.
- **Regularization**: Adding a penalty to the loss function to discourage overly complex models.
- **Residual**: The difference between a predicted value and the true value.

## S

- **Scaling**: Transforming numerical features to a common range or distribution.
- **Supervised learning**: Learning from labeled examples.
- **Sampling**: Selecting a subset of data to estimate properties of the whole.
- **Standard deviation**: A measure of how spread out a distribution is.

## T

- **Target**: The variable the model is trying to predict.
- **Test set**: A held-out dataset used only for final evaluation.
- **Training set**: The data used to fit the model.
- **True positive / false positive**: Correct and incorrect positive predictions.

## U

- **Underfitting**: When a model is too simple to capture the underlying pattern.
- **Unsupervised learning**: Learning patterns from unlabeled data.

## V

- **Validation set**: A dataset used to tune hyperparameters and compare models during development.
- **Variance (error)**: Error due to a model being too sensitive to small changes in the training data.
- **Vector**: An ordered list of numbers that can represent a data point or direction.

## W

- **Weight**: A learnable coefficient that determines the influence of a feature in a model.

## Z

- **z-score**: The number of standard deviations a value is from the mean.
